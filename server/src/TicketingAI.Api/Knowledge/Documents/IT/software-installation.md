## Standard software on your laptop
Every laptop includes Microsoft 365 with Outlook, Word, Excel, PowerPoint and Teams, a web browser (Edge and Chrome), the VPN client, and a password manager. These are updated automatically, so you do not need to update them yourself.

## Installing approved software
Open Software Center on your laptop to see the list of approved software, and click Install on what you need. Examples are Zoom, Slack, 7-Zip, Notepad++ and the printer drivers. Installation is automatic and normally takes a few minutes.

## Software that is not in Software Center
If you need software that is not listed, raise a software request ticket. Say what the software is, why you need it and for how long, and include the vendor website. Your manager must approve it, and IT does a security check before it is installed. Standard requests take up to 5 working days.

## Paid licenses
Software that requires a paid license needs approval from your manager and the budget owner. IT orders the license and installs the software. Licenses belong to the company and are reassigned when you leave.

## Administrator rights
Employees do not have administrator rights on their laptops. This protects the company from malware. If an installer asks for an administrator password, do not try to bypass it, but raise a software request ticket instead.

## Software that is not allowed
Pirated or unlicensed software, torrent clients, cryptocurrency miners and remote-access tools that were not approved are not allowed on company laptops. IT scans laptops, and unapproved software is removed. Repeated violations are handled under the code of conduct.

## Updates and restarts
Windows and security updates install automatically, and your laptop shows a restart reminder. Restart your laptop at least once a week, since updates only finish after a restart. Postponing the restart for more than 7 days forces it.
